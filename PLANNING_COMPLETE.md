## 📦 Планируемая структура пакетов

### Package 1: `@asciidoc-prosemirror/core`
**Назначение:** Базовая функциональность парсинга и сериализации
- Исходники: текущие `src/` и `test/`
- Размер: ~15-30KB
- Зависимости: asciidoctor, prosemirror-model (peer)
- Публикуется: ✅ Да

### Package 2: `@asciidoc-prosemirror/prosemirror`
**Назначение:** ProseMirror плагины и утилиты
- Исходники: новый функционал (input rules, keymap, commands)
- Размер: ~10-15KB
- Зависимости: @asciidoc-prosemirror/core (workspace)
- Публикуется: ✅ Да

### Package 3: `@asciidoc-prosemirror/vanillajs`
**Назначение:** Готовый к использованию редактор
- Исходники: `demo/src/AsciiDocEditor.tsx` → рефакторинг
- Размер: ~40-60KB (включая зависимости)
- Зависимости: core + prosemirror + ProseMirror библиотеки
- Публикуется: ✅ Да

### Package 4: `@asciidoc-prosemirror/demo`
**Назначение:** Demo приложение и E2E тесты
- Исходники: текущая `demo/`
- Зависимости: @asciidoc-prosemirror/vanillajs (workspace)
- Публикуется: ❌ Нет (private)

- **Package Manager:** pnpm (рекомендуется)

- **Версионирование:** Changesets

- **Тестирование:** Vitest + Playwright
