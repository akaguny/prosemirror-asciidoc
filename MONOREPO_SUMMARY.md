# Краткое резюме: Миграция на монорепозиторий

## 📋 Обзор

Проект планируется разделить на **4 пакета** в монорепозитории для улучшения модульности и удобства использования.

## 📦 Пакеты

### 1. `@asciidoc-prosemirror/core` ⭐ Основной
- **Что:** Парсер и сериализатор AsciiDoc ↔ ProseMirror
- **Для кого:** Разработчики, которым нужна только базовая функциональность
- **Размер:** ~15-30KB
- **Исходники:** Текущие `src/` и `test/`

### 2. `@asciidoc-prosemirror/prosemirror` 🔌 Плагины
- **Что:** Input rules, keymaps, команды для ProseMirror
- **Для кого:** Разработчики, создающие кастомные редакторы
- **Размер:** ~10-15KB
- **Исходники:** Новый функционал

### 3. `@asciidoc-prosemirror/vanillajs` 🚀 Готовое решение
- **Что:** Полностью настроенный редактор (как `AsciiDocEditor` из demo)
- **Для кого:** Пользователи, которым нужен ready-to-use редактор
- **Размер:** ~40-60KB
- **Исходники:** `demo/src/AsciiDocEditor.tsx` → рефакторинг

### 4. `@asciidoc-prosemirror/demo` 🎨 Демо (private)
- **Что:** Demo приложение с примерами
- **Для кого:** Разработка и тестирование
- **Публикация:** НЕ публикуется в npm
- **Исходники:** Текущая `demo/`

## 🔄 Сценарии использования

### Сценарий 1: Только парсинг (минимальный)
```bash
npm install @asciidoc-prosemirror/core prosemirror-model
```
```typescript
import { defaultAsciiDocParser } from '@asciidoc-prosemirror/core'
const doc = defaultAsciiDocParser.parse('= Title')
```

### Сценарий 2: Кастомный редактор (продвинутый)
```bash
npm install @asciidoc-prosemirror/core @asciidoc-prosemirror/prosemirror
```
```typescript
import { asciidocSchema } from '@asciidoc-prosemirror/core'
import { asciiDocKeymap, asciiDocInputRules } from '@asciidoc-prosemirror/prosemirror'
// Создание собственного редактора с плагинами
```

### Сценарий 3: Готовый редактор (простой)
```bash
npm install @asciidoc-prosemirror/vanillajs
```
```typescript
import { AsciiDocEditor } from '@asciidoc-prosemirror/vanillajs'
new AsciiDocEditor({ container: el, initialContent: '= Doc' })
```

## 📊 Сравнение: До и После

### До (текущая структура)
```
prosemirror-asciidoc/
├── src/              # Всё в одном пакете
├── demo/             # Отдельное приложение
└── package.json      # Один package.json
```
**Проблемы:**
- ❌ Всё в одном пакете (нельзя использовать только часть)
- ❌ Demo код копируется пользователями вручную
- ❌ Нет готового решения для быстрого старта

### После (монорепозиторий)
```
asciidoc-prosemirror/
└── packages/
    ├── core/         # Только парсинг
    ├── prosemirror/  # Плагины
    ├── vanillajs/    # Готовый редактор
    └── demo/         # Демо приложение
```
**Преимущества:**
- ✅ Модульная архитектура
- ✅ Готовый редактор в отдельном пакете
- ✅ Выбор: минимальный или полный пакет
- ✅ Лучшая поддержка и документация
